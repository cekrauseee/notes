this is a place for thoughts that do not need to become a finished argument
right away. each note has room to change, with its translations kept nearby.

the repository holds the writing and prepares its audio. the portfolio reads
that content and presents it, but the collection can exist without the site.

published notes include ai-generated narration and timing data for following
along with the text. generating that audio is part of publication, so listening
does not trigger another generation.
